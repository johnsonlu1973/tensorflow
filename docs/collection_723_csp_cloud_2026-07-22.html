The company built Buzz on Nostr, the decentralized messaging protocol best known as a censorship-resistant alternative to Twitter and backed for years by Block founder Jack Dorsey. Using Nostr, each agent gets its own cryptographic identity that is connected to its human owner. At first, Buzz looks a lot like Slack or Discord, with channels, threads, direct messages, voice, media sharing, and code repositories.
